## Project Description

### Domain
Productivity

Inspired by the "study until I finish this drink" concept, this application allows user to select a drink and set a timer. The drink will gradually decrease until the timer ends. The background of the timer will change according to the weather so that user can keep track of the weather outside when they are indoors. This application aims to increase productivity of users.

---

## User Stories

### User Story 1
As a user, I want to be able to set a timer to keep track of how long I want to study.
### User Story 2
As a user, I want to have a cute interface like a drink which decreases over time which will motivate me to study.
### User Story 3
As a user, I want to be able to select the drink that will be displayed with my timer.
### User Story 4
As a user, I want the background to change according to the weather so I can know what the weather is like outside when I'm indoors studying.
